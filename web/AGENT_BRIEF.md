# Snowfall — scene author brief

Browser game (three.js r170 via importmap, ES modules, no build step). Project root: `/home/claude/snowfall`.
A short first-person narrative game about grief. Quality bar: near-photoreal, atmospheric, restrained; it must look like the reference images. Read `js/text.js` for the full script and story; dialogue keys there are the ONLY player-facing text (do not hardcode strings; if you truly need a new line, add a key to text.js with both `en` and `ko` and say so in your report).

## Files you can read (do not rewrite shared files; small additive edits only if unavoidable — report them)
- `js/engine.js` — runtime. Exports: `E` (globals: E.camera, E.post, E.audio, E.flags, E.time, E.dt, E.ui), `player` (first-person controller: pos, yaw, pitch, eye, eyeTarget, speed, runSpeed, canMove, canLook, yawLimit {center,range}, pitchMin/Max, colliders [{minX,maxX,minZ,maxZ}], bounds(fn), onStep(fn), groundY(fn), moved (distance walked), speedScale, shake, roll, extraPitch, extraYaw, currentSpeed), `wait(s)`, `until(fn)`, `tween(dur, fn(k), ease?)`, `say(key, {dur, who, gap})`, `choose([keys]) -> index`, `go(sceneId, opts)`, `fadeIn(t)`, `fadeOut(t, color)`, `addInteract({pos|obj, radius, dist, label:'p.key', hold:seconds(0=press), onUse(it), repeat})`, `T(key)`, `input`, `currentEpoch()/alive(ep)`.
  - All script timing is game-time; write scene logic as async scripts using wait/until/say/choose/tween. Scripts are killed automatically when the scene changes.
- `js/post.js` — post stack. `E.post.snapLook({...})` / `E.post.setLook({...}, speed)` with keys: exposure, bloom, halation, focus, focusRange, dof, dofNear, lift[3], gamma[3], gain[3], sat, contrast, tint[3], vignette, ca, grain, rays, raysTint[3], raysThreshold, raysDecay, raysLen, raysSky, raysLight[uv x,y]. `E.post.fx`: fade (0..1), fadeColor (THREE.Color), warp, collapse, letterbox (0..1), glitch, desat. Particles that should not be blurred by DOF go on layer 1 (`mesh.layers.set(1)`, depthTest false, use `SOFT_GLSL`/`softFade` from post.js for occlusion) and set `scene.userData.soft = true`.
- `js/assets.js` — `model(name,{scale})` (Poly Haven scans in assets/models/*.glb), `pbr(texName,{repeat,...})` (assets/tex: snow_02, forest_leaves_02, forest_leaves_03, dry_decay_leaves, winter_leaves, asphalt_snow, old_wood_floor, dark_wooden_planks, bark_brown_02, red_plaster_weathered, leafy_grass, concrete_wall_008, rough_plaster_03), `setRepeat(mat,x,y)`, `hdri(name)` -> {env,bg} (snowy_field, snowy_park_01, sunny_rose_garden, autumn_park, winter_evening, reading_room), `snowCover(mat,{amount:{value}})`, `applySnowToObject(obj,u)`, `silhouette(obj,color)`.
  Models available: `ls assets/models` (wheelchair_01, GothicBed_01, ClassicNightstand_01, WoodenChair_01, ArmChair_01, wooden_ladder, brass_candleholders, wooden_candlestick, industrial_caged_sconce, wine_bottles_01, painted_wooden_bench, modular_street_seating, street_lamp_01, dead_tree_trunk, dry_branches_medium_01, fern_02, potted_plant_02, dandelion_01, flower_gazania, vintage_radio_transceiver, vintage_oil_lamp, throw_pillows_01, calathea_orbifolia_01, pachira_aquatica_01, shrub_02, tree_stump_01, rock_moss_set_01, wooden_bowl_01, Rockingchair_01, mantel_clock_01, antique_ceramic_vase_01, anthurium_botany_01, wooden_bookshelf_worn, book_encyclopedia_set_01). Check real-world size with a Box3 before placing.
- `js/fx/snow.js` — `Snow` (GPU snowfall; `.update(dt, camera)`, `.density=0..1`, `.wind`, `.timeScale`), `FogCards` (drifting fog curtains).
- `js/fx/foliage.js` — `makeTree`, `leafCards`, `daisyField`, `grassField`, `Drifters` (falling leaves/seeds; `.update(dt,t)`), `Butterflies`, `WIND` (set `WIND.uTime.value = t` each frame), `rng`.
- `js/fx/world.js` — `terrain`, `forest` (instanced, chunked; `.cull(z, range)`), `snowMaterial({sparkle})` (procedural snow, looks good), `fbm`, `vnoise`, `wineGlass`, `stainDecal`.
- `js/fx/textures.js` — canvas textures: mapleAtlas (4x4 autumn maple leaves), leafAtlas, bigLeafTex, twigTex, spineTex, glowTex, rugTex, seedTex, daisyTex.
- `js/fx/figures.js` — `makeMan({color,height})` → {group, root, acts, play('walk'|'idle'|'run'|'sad_pose'), pose(name|obj), update(dt)}: an animated dark silhouette (him). `makeHer({pose:'sit'|'lie'|'stand'|'sitSlump'|customObj, color, points, size, opacity, shellOpacity})` → {group, update(dt,t), uniforms (uDissolve 0..1 makes her drift apart into light), hipY, opacity setter, lightScale}: SHE IS ALWAYS A FIGURE MADE OF LIGHT (never a solid human). POSES are euler-degree offsets per mixamo bone; if a pose looks wrong, define your own pose object in your scene file rather than editing figures.js.
- `js/audio.js` — `E.audio`: `amb(name, level, fadeSec)` names: wind, birds, room, clock, vinyl, drone, heart, fire, kids, radio, hum; `stopAllAmb(t)`, `playMusic(name)` names: blizzard, garden, library, her, loop, red, waltz, end; `stopMusic(t)`, `step(surface('snow'|'wood'|'leaves'|'grass'|'stone'), speed, {gain, send, hall})`, `bell(pos,gain)`, `glass()`, `heartbeat()`, `whoosh(dur)`, `chime()`, `tapeStop(dur)`, `setWow(depth, flutter)`, `muffle(freq)`, `setHall(v)`, `setRev(v)`, `note(name,{vel,dur,when})`, `setListener(pos,fwd,up)`. Always guard with `E.audio?.`.
- `js/scenes/blizzard.js` — THE REFERENCE IMPLEMENTATION. Copy its structure: factory `export async function xScene(opts)` builds a THREE.Scene, returns `{ scene, enter(opts), update(dt,t), lateUpdate?, exit?, dispose(), customCamera?, customPlayer? }`. `enter()` positions the player, sets `E.post.snapLook(...)`, starts audio and kicks off the async script. Set `obj.customCamera = true` for cutscenes where you drive `E.camera` yourself.

## Contract between scenes (flags + where to go next)
- Flags live in `E.flags`. Returning to the hub: `go('library', { spawn: '<id>', color: 0xffffff, fadeOut: 0 })` after your own fade (memories end by fading to WHITE: `await fadeOut(2.2, 0xffffff)`; red fragments end with a hard cut: `E.audio?.tapeStop(1.2)`, glitch, then fade to black).
- park (first meeting memory): set `E.flags.m_park = true`, spawn `'book'`.
- field (snowfield memory): set `E.flags.m_field = true`, spawn `'globe'`.
- road visit 1 (`opts.visit === 1`): `E.flags.road1 = true`, spawn `'window'`. Visit 2 (`opts.visit === 2`, after the reunion): finish by `go('bench')`.
- red fragments (`opts.frag` 1..3): set `E.flags['r'+frag] = true`, spawn `'door'+frag`.

## Testing (headless Chrome + SwiftShader, slow: ~2 s/frame at low quality)
A static server already runs at http://localhost:8765 (do not start another). After editing index.html (you shouldn't need to), run `/home/claude/tools/mkdev.sh`.
Capture: `cd /home/claude/tools && timeout 250 python3 shot.py "http://localhost:8765/dev.html?scene=<id>&manual&q=low&opts=<urlencoded json>&flags=<json>" /home/claude/shots/<name>.png 1 "(async()=>{await SF.sim(<seconds>); /* tweak SF.player.yaw etc */ SF.renderOnce(); return 1})()" 960 540 150`
- `SF.sim(sec)` advances game time WITHOUT drawing (scripts run), `SF.renderOnce()` draws one frame. `SF.player`, `SF.E`, `SF.THREE`, `SF.input` are exposed. To fake input in sim: `SF.input.keys.add('KeyW')`, `SF.input.interactPressed=true`, `SF.input.interactHeld=true`, `SF.E.ui.pickChoice(0)`.
- Look at every capture with the Read tool and compare against the reference image (in `/home/claude/ref/`). Iterate on what is visibly off (composition, colour, scale, light). The machine has 2 CPUs and other agents render too: keep each capture at 960x540 low quality, and budget ~10–14 captures.
- Performance budget (real users, mid GPUs): ≤ ~600k triangles visible, ≤ ~250 draw calls, ≤ 4 shadow-casting lights (prefer 1). Use instancing for repeated things.

## Style rules
- Restraint. No UI text except via `say`/`choose`/prompts. Lines are short; let silence and sound work.
- One dominant colour per state. Guide the player with light, not arrows. Keep each scene playable in the stated time.
- Never show her as a solid person. Him: either first person (player) or a dark silhouette (`makeMan`).
- Write clean, commented code in your own scene file only.
